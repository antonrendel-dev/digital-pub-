## Как собрать портфолио копирайтера с нуля: 7 шагов

1. Выбери 7 форматов текстов из трёх ниш: eCommerce, услуги и контент-маркетинг — SEO-статья, карточка товара, лендинг, пост для соцсетей, email, пресс-релиз, экспертная колонка
2. Пиши один текст в день — за 14 дней получишь базовый набор
3. Для каждого текста добавь блок контекста: задача, целевая аудитория, объём, ключевые слова, цель
4. Оформи портфолио в Google Docs, Notion или Tilda — с оглавлением по форматам
5. Настрой доступ «только просмотр» по ссылке — без запросов авторизации
6. Начни откликаться с 3–4 готовыми примерами — не жди, пока наберёшь десять
7. Добавляй тексты по мере появления реальных заказов — портфолио живёт, не замирает

## Почему учебные тексты принимают наравне с коммерческими

Портфолио копирайтера — подборка текстов-образцов, по которым заказчик оценивает стиль, мышление и соответствие нише. Не коллекция оплаченных работ. Инструмент продажи себя как специалиста.

На самом деле замкнутый круг — миф. В описаниях junior-вакансий на hh.ru работодатели прямо пишут: «любые примеры работ, в том числе учебные и личные проекты». Это не интерпретация — это дословная формулировка из реальных вакансий 2026 года. По данным крупных job-платформ, более 70% позиций без требования к опыту допускают любые форматы примеров.

Отказывают не из-за отсутствия оплаченных кейсов. Отказывают из-за отсутствия примеров вообще.

Мы в Диджитал Паб разбираем тысячи вакансий каждую неделю и видим одно и то же: работодатели в digital куда лояльнее к учебным текстам, чем принято считать. Главная причина отказа — плохое оформление работ, а не их происхождение. Копирайтер с тремя сильными текстами в Google Docs получает ответы значительно чаще того, кто обещает прислать примеры «по запросу». Заказчик хочет видеть работы сразу — не после знакомства. Тренировочный текст с прописанным контекстом — задача, целевая аудитория, цель — воспринимается как профессиональный кейс. Не история создания, а форма подачи формирует первое впечатление об авторе.

## Какие 7 текстов написать за 2 недели: план начинающего копирайтера

Чтобы закрыть ожидания заказчиков из разных сегментов, нужно охватить три базовые ниши: eCommerce, услуги и контент-маркетинг. По методике оценки исполнителей на Etxt, 5–7 разноплановых примеров перекрывают 30 однотипных SEO-текстов — заказчик оценивает форматное разнообразие, а не объём папки.

| День | Формат | Тема примера |
|---|---|---|
| 1–2 | SEO-статья | «10 советов по выбору ноутбука для удалённой работы» |
| 3–4 | Экспертная колонка | «Как настроить домашний офис за 15 000 ₽» |
| 5–6 | Продающий текст лендинга | Онлайн-курс по Excel для бухгалтеров: оффер, боли, закрытие |
| 7–8 | Карточка товара | Наушники Sony WH-1000XM5: характеристики + выгода + CTA |
| 9 | Пост для ВКонтакте | Акция кофейни: эмоция + оффер + призыв |
| 10–11 | Email-рассылка | Реактивация подписчиков интернет-магазина спортивного питания |
| 12–14 | Пресс-релиз | Открытие нового коворкинга в Москве |

SEO-статья и экспертная колонка закрывают контент-маркетинг. Карточка и лендинг — eCommerce и услуги. Email и пост — digital-коммуникации. Набор одновременно отвечает запросам заказчиков с FL.ru, Kwork и из штатных вакансий.

**Как писать лучше с первого текста.** Для SEO-статьи — работай по реальным запросам из Яндекс.Wordstat: сразу привыкаешь к структуре, которую ждут клиенты. Для карточки товара — изучи топ-листинги на Wildberries или Ozon, смотри, какие выгоды они выводят в первый абзац. Для лендинга — разбери 2–3 посадочные страницы конкурентов в нише. Это не копирование. Это профессиональная насмотренность.

Конкретный продукт в теме обязателен. Не «техника», а «наушники Sony WH-1000XM5». Не «курс», а «онлайн-курс по Excel для бухгалтеров». Конкретика — это и тренировка, и сигнал заказчику, что автор понимает целевую аудиторию.

## Три платформы для портфолио: пошаговая инструкция

Личный сайт при поиске первого заказа не нужен. Правила FL.ru и Kwork прямо допускают ссылки на Google Docs, Notion и Tilda. Три инструмента с разным порогом входа и разной аудиторией. И с одинаковым принципом: заказчик оценивает каждый текст через призму общего впечатления от портфолио. Чистая структура, понятный контекст и аккуратное оформление автоматически поднимают планку восприятия отдельных образцов — даже прежде чем прочитана первая строка.

### Google Docs — универсальный старт

**Шаг 1.** Создай новый документ. Первая страница: имя, специализация («SEO-копирайтинг / продающие тексты / контент»), контакты — Telegram и email.

**Шаг 2.** Добавь оглавление с якорями по форматам: SEO / Продающие / Email / PR / Карточки товаров.

**Шаг 3.** Перед каждым текстом — блок из 3–4 строк: задача → целевая аудитория → объём → ключевые слова (для SEO) → цель текста.

**Шаг 4.** Установи режим «Доступ по ссылке — только просмотр». Заказчик открывает файл без запроса доступа. Значительная часть отказов без объяснения причин происходит именно здесь: появляется запрос авторизации — вкладка закрыта.

Google Docs удобен для заказчиков малого бизнеса, которые не работают с Notion.

### Notion — для digital-агентств и IT-компаний

**Шаг 1.** Создай базу данных в галерейном виде — каждая карточка соответствует одному тексту.

**Шаг 2.** Добавь теги по нише (eCommerce / услуги / контент-маркетинг) и формату (SEO / email / лендинг / PR).

**Шаг 3.** Для каждой карточки заполни те же 5 полей: задача, ЦА, объём, ключевые слова, цель.

**Шаг 4.** Настрой фильтрацию: заказчик из Яндекса или небольшого продуктового стартапа видит только релевантный сегмент — без прокрутки всего архива.

Создание Notion-портфолио занимает 2–3 часа. Платный аккаунт не нужен.

### Tilda — когда важна визуальная подача

**Шаг 1.** Зарегистрируйся на Tilda. Бесплатный план — один сайт, до 50 страниц.

**Шаг 2.** Выбери шаблон портфолио или начни с чистого холста — используй блоки ST для текстовых страниц.

**Шаг 3.** Создай главную страницу с навигацией по форматам: SEO, продающие тексты, email, PR.

**Шаг 4.** Для каждого текста — отдельная страница с контекстом: задача, целевая аудитория, ожидаемый результат.

**Шаг 5.** Подключи поддомен Tilda (формат name.tilda.ws) — работает без покупки домена.

Tilda актуальна при работе с брендами и агентствами, где визуальная подача усиливает первое впечатление. Для первых откликов на бирже — Google Docs достаточно.

Именно контекст вокруг текста превращает набор файлов в профессиональный инструмент продажи.

## Три мифа о портфолио копирайтера с нуля

Три убеждения стабильно удерживают начинающих от первого отклика. Ни одно не подтверждается правилами реальных платформ.

**Миф 1 неверен — по данным hh.ru:** в описаниях junior-вакансий работодатели прямо пишут «любые примеры работ, в том числе учебные и личные проекты» — это дословная формулировка, а не интерпретация. Требование именно коммерческого клиента в позициях без опыта — исключение, а не правило.

**Миф 2: без личного сайта несерьёзно.** Правила FL.ru и Kwork прямо допускают ссылки на Google Docs и Notion. Отдельный домен нужен при переходе к высококонкурентным нишам — не при поиске первого заказа.

**Миф 3: чем больше текстов — тем лучше.** По методике Etxt, 5–7 разноплановых примеров перекрывают 30 однотипных SEO-текстов. Три страницы с похожими информационными статьями не заменяют одного продающего поста или карточки товара.

Один хорошо оформленный кейс с контекстом «задача → ЦА → цель» работает сильнее, чем десять файлов с голым текстом.

## Кому этот план не подойдёт: 4 сценария

Маршрут через тренировочные тексты закрывает большинство стартовых ситуаций. Но у него есть границы применимости — лучше знать о них до, а не после двух недель работы.

- **B2B high-ticket клиенты** — требуют не менее 3 кейсов с измеримыми результатами: рост конверсии, ROI, прирост трафика. Учебный текст здесь не работает как аргумент.
- **Экспертные ниши: медицина и юриспруденция** — без профильного бэкграунда тексты не пройдут редактуру заказчика независимо от оформления.
- **Агентский рынок** — минимальный порог входа в ведущие контент-агентства: 3–5 коммерческих кейсов.
- **Ориентация на быстрый доход** — стартовые ставки на FL.ru и Kwork для начинающих: 500–2 000 руб./текст. До 50 000 руб./мес — несколько месяцев активной работы.

| Ситуация | Рекомендация | Почему |
|---|---|---|
| Нужен агентский рынок | Стажировка в контент-агентстве | Коммерческий кейс за 1–2 месяца |
| Нужен реальный клиент без ниши | Бесплатный проект для НКО или стартапа | Кейс с метриками + разрешение на публикацию |
| Медицина / юриспруденция | Нишевые курсы с практическими кейсами | Подтверждает экспертизу в теме |
| Есть экспертиза из другой профессии | Нишевый копирайтинг по своей теме | Конкурентное преимущество без переобучения |

После 15–20 заказов на биржах фриланса средний чек вырастает с 500–2 000 до 3 000–6 000 руб./текст — по данным FL.ru за 2026 год. Это линейный рост, а не скачок.

## FAQ: частые вопросы о портфолио копирайтера с нуля

### Можно ли стать копирайтером без профильного образования?

Да. По данным hh.ru, большинство вакансий копирайтера не требуют диплома по журналистике или филологии. Работодатели оценивают примеры текстов, а не строку об образовании.

### Сколько времени нужно, чтобы собрать портфолио копирайтера с нуля?

14 дней при темпе один текст в день. Минимально достаточный набор — 5 разноплановых работ: SEO-статья, продающий текст, email, карточка товара, пост для соцсети. С 3–4 примерами можно начинать откликаться уже на второй неделе.

### Можно ли работать копирайтером удалённо без опыта?

Да. FL.ru, Kwork и [вакансии для копирайтеров](/vacancies/copywriting) на Диджитал Паб регулярно публикуют удалённые позиции для начинающих. Фильтр «без опыта» на hh.ru в категории копирайтинга даёт стабильный поток предложений.

### Что делать, если заказчик отказывает из-за учебных текстов?

Предложить бесплатное тестовое задание по его теме. Заказчик видит работу под свою задачу и принимает решение — это конвертирует лучше, чем любой спор о формате портфолио. Тестовое задание сразу попадает в портфолио как первый реальный кейс.

### Как перейти в копирайтинг из другой профессии?

Использовать экспертизу из прошлой сферы. Врач пишет медицинские тексты, юрист — юридические разборы для B2C, маркетолог — кейсы и аналитику. Нишевая экспертиза — конкурентное преимущество перед универсальными копирайтерами без специализации.

### Сколько текстов достаточно для первого портфолио?

5–7 разноплановых примеров. По методике Etxt, разнообразие форматов — главный критерий оценки, а не количество. Новые тексты добавляй по мере появления реальных заказов, не ради объёма.

### Google Docs, Notion или Tilda — что выбрать?

Для первых откликов на FL.ru и Kwork — Google Docs: открывается без авторизации, понятен любому заказчику. Notion удобнее для digital-агентств и IT-компаний, например Яндекса или небольшого продуктового стартапа — галерея с фильтрами ускоряет проверку. Tilda — при работе с брендами, когда важна визуальная подача. Начни с Google Docs, перейди на Tilda при первых прямых клиентах.

### Нужно ли проходить курсы перед созданием портфолио?

Необязательно. Базовые принципы SEO-текстов и продающих форматов осваиваются за 3–5 дней по бесплатным материалам. Курс ускоряет вход в профессию, но не обязательный этап для написания первых тренировочных текстов.
