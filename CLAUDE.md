## Факты — подтверждать с двух сторон, ОБЯЗАТЕЛЬНО

Прежде чем заявить, что система ведёт себя определённым образом, подтверди это
**минимум двумя независимыми сигналами**. Строка в кроне, конфиге или доке — это
намерение, а не доказательство исполнения.

Независимые подтверждения: наличие и время записи лог-файла; сколько артефактов
реально создано и когда; сходятся ли даты и дни недели с расписанием; `git log`
по затронутым файлам; прямой прогон на живых данных.

Правило жёстче всего, когда вывод звучит тревожно («сломано», «теряются данные»,
«работает не так»). Нет второго подтверждения — так и пиши: «в конфиге стоит X,
следов запуска не нашёл, проверяю».

Повод: 20.08.2026 вывод о работе контент-завода был сделан по одной строке крона.
По факту аналитик по этому крону не запускался ни разу — лога не существовало,
а даты батчей не совпадали с расписанием.

## Agent Quality Gates — ОБЯЗАТЕЛЬНО

Агенты принимают работу друг друга. Задача НЕ считается выполненной без вердикта принимающего агента.

| Кто делает | Кто принимает | Критерий приёмки                                                 |
| ---------- | ------------- | ---------------------------------------------------------------- |
| writer     | seo           | Контент соответствует ТЗ: объём, ключи, структура H2, FAQ по 2.5 |
| dev        | review        | Код без P0/P1 замечаний из code-review                           |
| seo        | analyst       | Данные проверены на актуальность, позиции/частоты подтверждены   |
| marketer   | seo           | SEO-импликации контент-плана проверены                           |

**Как работает цепочка:**

1. Агент A выполняет задачу → коммитит/сохраняет результат
2. Агент A явно указывает в итоге: «Готово для проверки агентом B»
3. Оркестратор (Claude) запускает агента B с результатом агента A
4. Агент B даёт вердикт: «Принято» или «Не принято — правки: [список]»
5. При «Не принято» → агент A исправляет → цикл повторяется (макс. 2 итерации)

**Без финального «Принято» от принимающего агента — задача в Todoist не переносится в «Готово».**
